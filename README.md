# PromptMotion — AI Motion Design Prompts and Examples

[PromptMotion](https://promptmotion.art) is a free, public library of AI motion design prompts and examples.

Every case names the model that made it, links back to the original post or repository, and — when the author shared it — shows the exact prompt with a one-click copy button.

## What you will find

- Real AI-made motion graphics, product films, shaders, Three.js scenes, games, and web designs
- Model labels such as Claude Opus, Claude Fable, GPT, Grok, MiniMax, and Seedance (as listed on the site)
- Browse by model, by type (video and web design), and by technique
- English and Simplified Chinese
